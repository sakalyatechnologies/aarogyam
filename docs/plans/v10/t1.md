# v10 T1 + T2: home choice and availability strip (handoff)

Kotlin only, `mobile/shared`. No `AppGraph`, `NavModel` or iOS edits: the T0 seams `graph.homeChoice(clinic, scope)` and `graph.availability(clinic, scope)` return the interfaces below.

## Public API (for iOS T7 and T9)

**`nav/HomeChoice.kt`**
- `enum Home { Doctor, Desk, Default }`
- `data class HomeChoice(home: Home, deskReachable: Boolean, practitionerId: String? = null)`
- `fun homeChoiceOf(permissions: Set<String>): HomeChoice`, pure, by permission key:

| Permissions | home | deskReachable |
|---|---|---|
| `queue.call` | Doctor | true if also `queue.write`, `payments.collect` or `billing.write` |
| any of those three, no `queue.call` | Desk | true |
| else | Default | false |

**`nav/HomeChoiceHolder.kt`**: `interface HomeChoiceHolder { val choice: StateFlow<HomeChoice> }`. Known at once. For Doctor, `practitionerId` fills in after `reference.practitioners()` loads (matched on `membershipId`); it stays null with no doctor profile, so Today should then be unfiltered. Desk and Default never request doctors.

**`desk/AvailabilityModel.kt`** (pure)
- `availabilityOf(today: TodayResponse, tokens: List<QueueToken>, nowMinute: Int): AvailabilityStrip`
- `AvailabilityStrip(doctors: List<DoctorSlot>, chairs: List<ChairSlot>)` with `freeDoctors`, `freeChairs`.
- `DoctorSlot(id, name, availability: Free|WithPatient|Away, patients)`; `ChairSlot(roomId, name, kind, availability: Free|Busy, tokens)`.

**`desk/AvailabilityHolder.kt`**: `AvailabilityHolder { state: StateFlow<AvailabilityState>; refresh(); observe(live) }`; `AvailabilityState` is `Loading | NotAllowed | Failed(error) | Loaded(strip)`. One `/today` plus one `/queue` per refresh (no new endpoint); a failed refresh keeps the last strip. Needs `appointments.read`, otherwise `NotAllowed` with no request. "Now" is the `/today` `as_of` in the clinic zone, so a skewed phone clock cannot lie.

## Rules (R6)
- Doctor: token `called` or `in_chair` for their practitioner id is WithPatient, and wins over leave and out-of-shift (the patient is there). Else on leave, no shift, or outside every shift (start inclusive, end exclusive, split shifts handled) is Away. Else Free.
- Chair: Busy when `ChairStatus.current` is set or a token with that `room_id` is waiting, called or in_chair. Done, left and ready_to_bill free it. A token with no room marks nothing; a room id not in `/today` chairs is ignored. Two tokens in one chair are one Busy chair with `tokens = 2`.

## Gaps
- No `ServerCaps` work was needed here (no new fields read).
- Doctors are matched by token `practitioner.id` only; an in-chair appointment with no queue token does not mark its doctor busy.
- Shows `ready_to_bill` as freeing the chair; if the desk wants the chair held until billing, change `SEATED` in `AvailabilityModel.kt`.
- The Doctor home's "Waiting for you" card itself is T7/T8 work: it uses `queue(practitionerId)` from `HomeChoice.practitionerId`. `NavModel` is untouched, so the Desk tab and the Doctor/Desk switch need the shell to read `HomeChoice` (a seam for the coordinator).
