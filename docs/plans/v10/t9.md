# t9: iOS doctor journey (waiting card, chair mode, Wrap up)

Files: `Screens/DoctorV10/*`, `Routes+V10Doctor.swift`, `DoctorV10.xcstrings` (en/hi/mr), `IosDoctorV10.kt`, `DoctorV10FormatTests`.
V9 edit: one line in `V9VisitContent` adds Chair mode and Wrap up buttons above the notes.

- Waiting card: `DoctorWaitingHolder` (iosMain) polls `queue(practitionerId)` every 20 s, keeps `waiting` only, Send in = `callToken`.
  The hook has no layout space, so the card opens as a sheet on a new arrival (banner shows the token number, plus a haptic).
- Chair mode: dictation via `VisitStateHolder.listen`, Photo via `writes.photo` (selected tooth attached), autosave every 8 s and on close.
- Wrap up: `finishVisit` holder, chips, fee prefill, Rx toggle, override reason, offline banner, celebration.

Seams (commonMain is off limits):
1. `RxSheetStateHolder` keeps its draft id private, so Wrap up pushes the Rx lines through its own `RxDraftSync`
   (internal, same module). A doctor who also pressed Save draft in the Rx card may get a second draft. Fix: expose `draftId` on the holder.
2. `DeskPaymentSheet` takes a patient (`DeskPayTarget`), not an invoice id, so Collect now opens it for the patient.
3. Dictation keeps no audio, so `ChairRecorder` (AVAudioRecorder, 600 s cap) records beside the recogniser, then `enqueueAudio`
   with `noteId = nil` (the note's client id is not exposed). Not device-tested: the microphone may refuse two readers.
4. `AppGraph.outboxFiles` is private, so `enqueueDictationAudio` builds its own `ProtectedOutboxFiles()` (same folder).
5. The hook signature has no screen state, so no persistent badge, only the sheet.
