# t8 - iOS one-form new-patient intake

Branch `v10-t8`. SwiftUI over the shared `IntakeFormHolder` (SKIE); no Kotlin changed.

- `RoutesV10Intake.screen(graph:clinic:phone:onDone:)` opens the form (Desk home "New patient" calls it); `hook` stays invisible.
- `Screens/IntakeV10/`: `IntakeV10Screen` (one scrolling form, `ScreenHost` owns the `ScreenScope`),
  `IntakeV10Signature` (PencilKit pad, finger allowed, white ground, PNG to `setSignature`), `IntakeV10Logic` (pure helpers).
- Form order: phone, name, DOB/age toggle, email, sex, allergies + None known, notice + read-aloud + reminders,
  signature, photo (camera or library), doctor chips, reason (only `showReason`), Save & queue.
- DOB box auto-inserts dashes from digits. Photo: long edge 1280, JPEG at most 2 MB (quality steps down).
- Offline/server errors show a banner and keep the form; `done` shows "Token N · added to queue" and Next patient (`reset()`).
- Strings: `IntakeV10.xcstrings` (en/hi/mr), table `IntakeV10`, helper `iv(_:)`.
- Tests: `IntakeV10Tests` (photo size, PNG not empty, date text, error mapping).
- Not done: `showFamily` (family-of picker) has no UI yet; needs a patient search.
