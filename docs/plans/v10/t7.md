# v10 T7: iOS Desk home (handoff)

Branch `v10-t7`. iOS only (`mobile/iosApp`). Gate: `ios-check.sh` on "iPhone Air", exit 0.

## Built
- **Desk home** (`DeskHomeScreen`): availability strip, a number field focused on appear (numeric keypad), automatic search at 10 digits through the existing `DeskLookupStateHolder`, profile chips, `Check in · Dr X` on the picked profile (chosen chip, else the last doctor if free, else any free doctor, else the last doctor), doctor chips to change it, "New patient", and the board below.
- **"New patient"** calls `onNewPatient: ((String) -> Void)?` (the typed number). nil opens the existing walk-in sheet on its form (`DeskSheet(start:)`). T8 passes a closure through `RoutesV10Desk.home(graph:clinic:onNewPatient:)`.
- **Strip** (`AvailabilityStripView`): doctors free / with a patient / away, chairs free / busy, wrapping `SkChip`s with a11y labels.
- **Board cards** (`DeskBoardScreen`, extended with `feed` and `embedded`): waiting card shows "Waiting for Dr X · 0:42" (ticks each second from `issued_at`); from 60 s an amber "Check with Dr X"; no Remind button (see gaps); Called banner uses token numbers only ("Token 12 is called"); a `ready_to_bill` card says "Doctor may be collecting".
- **To-pay card closes**: `DeskPaymentSheet` calls `checkHandled(notificationId)` on every live refresh (`refreshTick`) and dismisses when `cardOpen` turns false while no result of its own is showing (so the "Paid" celebration is kept). `DeskPayTarget.notificationId` comes from `/notifications` (`collect_payment` row by token id).
- **Flags**: lookup family button and relative controls, the walk-in family bar, and the payment proof section are hidden unless `ServerCaps.shared.family` / `.paymentProof` are on.
- **Shell**: `RoutesV10Desk.hook` shows the Desk home full-screen on launch when `homeChoiceOf(permissions).home == Desk` (toolbar "All tabs" returns to the tab bar); others get the zero-size placeholder. `RoutesV10Desk.home(...)` is the same screen as a view for a Desk tab (`deskReachable`), which needs a `MainTabs` edit.
- Strings: `DeskV10.xcstrings` (en/hi/mr, 30 keys, `dx` / `dxf` helpers).

## Gaps and seams needed
1. **No iosMain wrapper for `AvailabilityHolder`, `WaitTimerHolder`, `HomeChoiceHolder`.** They take a `CoroutineScope`, and `ScreenScope.scope` is internal, so Swift cannot call `graph.availability(...)`. `DeskV10Feed` therefore makes the same `/today`, `/queue`, `/notifications` calls and folds them with the public pure `availabilityOf` and `homeChoiceOf`. Fix: add `fun AppGraph.availability(clinic, screen: ScreenScope)` and `waitTimer`, `homeChoice` in `IosDesk.kt`; then swap `DeskV10Feed` for the holders. Rules are identical (60 s threshold in `DeskV10Wait`).
2. **Remind** is not drawn: it needs the G1 flag and `WaitTimerHolder.remind`, which Swift cannot reach (gap 1). `DeskV10Caps.showsRemind` is ready.
3. **Last doctor** comes from today's queue only (the lookup carries none); with no token today the free doctor is used.
4. **Doctor may be collecting** uses the token's `done_at` (the desk has no `clinical.read` for the visit's `ended_at`); with no `done_at` it stays hidden.
5. **Check in** with a doctor calls `registerWalkIn` from Swift (the lookup holder's `checkIn` takes no doctor), online only, like the lookup's.
6. The Desk tab and Doctor/Desk switch need a `MainTabs`/`NavModel` edit (coordinator); the cover is the stand-in.
7. `ServerCaps.family` turns on only after a lookup returns `family_group` (T0 note), so family controls appear after the first lookup.
