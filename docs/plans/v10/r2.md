# r2: desk payment for assistants
- `DeskPaymentStateHolder` takes `invoiceId: String? = null` (before `log`); allowed = billing.read+write, or payments.collect with an invoiceId.
- With payments.collect and an invoiceId, `load()` makes one `collectSummary` call; `Ready` has one due with `upi` set; balance <= 0 gives no dues and closes the card.
- The 409 refetch uses `collectSummary` when the person has payments.collect, else `invoice()`.
- `recheck(..., canCollect)` falls back to `invoice()` (old logic, draft issued first) without payments.collect.
- iOS: `AppGraph.deskPayment(clinic, patientId, invoiceId, screen)` overload added.
- Tests: `DeskAssistantPayTest` (5); `DeskCollectRaceTest` now uses payments.collect perms.
