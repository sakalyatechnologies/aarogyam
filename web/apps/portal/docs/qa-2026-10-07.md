# Portal QA, 7 Oct 2026

Branch `fix/portal-qa` (from `feat/portal-redesign`). Fake API (`VITE_API_MODE` unset = `fake`), driven with Playwright as Asha (owner), Dr Dev (doctor, both clinics), Farah (front desk) and a custom "Roles only" role (roles.manage, no staff.manage, invited and joined through the UI). Widths 1440, 1024 and 390. Every route and tab was visited; console errors and warnings: none on any screen.

## Checked and fine

- Sidebar is sticky and 100% of the viewport height on every route, including after scrolling a 1,700 px page. Collapses to a drawer below 1100 px.
- Today, Patients, Patient 360 (Overview, Chart incl. recording a finding with procedure and material, Visits, Rx with Load more (10 per page), New prescription, Quick Rx, Files upload, Notes editor, Clinical flags, Billing), Billing (record payment, exact balance), Calendar day, week and month, Queue, Stock, Messages, Settings (every tab), Roles and access editor (create, edit, confirm), import wizard, command palette (Ctrl+K, search, Escape), clinic switcher, sign-out, invite flow.
- Money: Today and Billing hide revenue, collections and pending reports without `finance.view`; the patient list hides balances without `billing.read`; prices tab needs `billing.read`.
- Empty states (no Rx, no files, no visits, no bills) read well; loading skeletons appear; 404 page renders.

## Not fixed (for a decision)

- Settings has no way to change an existing member's role (only suspend or remove); the API supports it.
- Sidebar clinic name truncates ("Sunrise De...") beside the collapse button; the full name is on the switcher card below.
- The disabled "Message" button on Patient 360 is low contrast by design ("Coming soon").
- Upload dialog uses the browser's unstyled file input, and Kind stays "Document" after choosing an image.
- Billing "Weekly collections" says "Last 8 weeks" but shows only weeks with data.
- Notification toggles are disabled placeholders (marked "not available yet").
