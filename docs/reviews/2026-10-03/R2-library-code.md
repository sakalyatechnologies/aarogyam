## Top v0.2 additions
Backend: (1) auth extractor/layer that rejects anonymous sessions, records user_id, inserts Claims + ClientIdentity, with key prefetch and single-flight refresh; (2) `db.scoped` API (one-round-trip setup, local timeouts, awaited rollback, retry on 40001/40P01), sqlx Encode/Decode for Id/Paise/Slug/PhoneE164 behind a feature, testkit RLS helpers; (3) HTTP kit: ApiJson/ApiQuery/ApiPath, 422 field errors, JSON timeout/413, `Cache-Control: no-store` + `nosniff`, CORS helper, trace links, connect info + drain deadline; (4) trustworthy client-IP extractor, split throttle layers, batched unlogged hashed Postgres store; (5) append-only audit writer inside the scoped transaction; `Idempotency-Key` layer.
Web: (1) form kit on Base UI (Field, Input, Select, DatePicker, +91 PhoneInput) mapped from API field errors; (2) Dialog/Drawer/Menu/Popover/Toast themed in portals + mobile AppShell; (3) DataTable + Skeleton/EmptyState/ErrorState; (4) typed API client returning Result<T, ApiError>, en-IN Intl formatting, en/hi/mr strings; (5) status text tokens + vitest-axe and Playwright a11y/visual tests.
